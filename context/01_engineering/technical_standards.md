# Technical Standards

## Programming Languages
- **Primary**: Python
- **Secondary**: Java, C++
- **Tertiary (Learning/Adapting)**: JavaScript, C, Assembly, C#, Elisp

## Environment & Tooling
- **OS**: Windows (Primary driver)
- **IDE**: Antigravity IDE
- **Version Control**: Git / GitHub
- **Other Go-To Tech**: ROS, NVIDIA Isaac Lab, PyTorch, React, Node.js, Express, MongoDB, Docker, Linux, Solidworks, 3D Printing.

## Project & Code Guidelines
1. **Testing**: Automated test cases must be written and run after any feature is added. Projects require a large test bank file that is constantly run during active development.
2. **Project Bootstrapping**: Every new software project must be immediately initialized with a `context.md` file outlining the expectations for the project.
3. **Style Guides**: Currently unopinionated, but AI should outline differences in style guides (e.g., PEP 8 vs. Google) when initializing projects to allow for an informed choice.
