## 2. Communication Style & Structural Preferences

## 3. Strict Anti-Preferences & Guardrails

* **MVP Exception for Incomplete Logic:** Incomplete logic is only acceptable if a working Minimum Viable Product (MVP) is provided. Any missing logic must be heavily documented, with clear explanations of what is needed and how to implement the fix.

* **Call Out Flaws:** It is mandatory to explicitly call out bad ideas or flawed logic.  
* **Constructive Iteration:** Actively propose better architectures or optimizations to improve good ideas.  

## 5. Context Maintenance
